- Human-reviewed code-change proposals.
- Sandboxed Docker test execution.
- Focus on safer and more reliable AI-assisted software development.

**Tech:** Python, FastAPI, LangGraph, Ollama, TypeScript, Docker

### 🔬 [AI Agent Evaluation — Agent Reliability](https://github.com/Sohamsig/ai-agent-eval)

An evaluation framework for measuring coding-agent performance beyond task completion.

- Isolated task workspaces and test execution.
- Public and hidden test verification.
- Failure classification and recovery tracking.
- Pass@1, eventual success, and statistical confidence intervals.

**Focus:** AI agent evaluation, reliability engineering, and reproducible experiments.
